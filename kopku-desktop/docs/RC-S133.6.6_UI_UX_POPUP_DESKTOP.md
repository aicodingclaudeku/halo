# RC-S133.6.6 — UI/UX popup desktop (Windows 1.0.21)

Permintaan: *"perbaiki beberapa UI/UX desktop, terutama popup — jangan mengikuti versi Android"*.
Hanya tampilan **desktop** (bundel web/Electron). Aplikasi Android, aturan bisnis, data, dan skema
(**tetap v82**, tanpa migrasi) tidak berubah. HP versi RC-S133.6.5 tetap dapat sinkron dengan desktop 1.0.21.

## 1. Dialog notifikasi & konfirmasi (`src/components/AppNotificationHost.web.tsx`)

| Sebelumnya (kartu ala Android) | Sekarang (kotak dialog desktop) |
|---|---|
| Ikon bulat besar berlatar warna, judul & pesan di samping | Bilah judul: ikon kecil berwarna + judul + tombol **×** |
| Tombol utama berwarna sesuai jenis (hijau/oranye/biru/merah) | Tombol utama selalu **hijau brand**, **merah** hanya untuk aksi destruktif; tombol lain bergaris netral |
| Batal di kiri, aksi di kanan; padding besar, sudut 14 px | Urutan dialog Windows: **tombol utama paling kiri, Batal/Tutup paling kanan**, bilah tombol abu-abu muda bergaris atas, tombol 32 px, sudut 8 px |
| Fokus awal di tombol pertama (sering *Batal*) — Enter menjalankan Batal | **Fokus awal di tombol utama** (cincin fokus terlihat): Enter = tombol utama, Esc = Batal/Tutup, Tab = pindah tombol. Masing-masing tepat **sekali** (diuji) |

Fungsi tidak berubah: store `useNotifyStore`, `notify(title, message, buttons, type)`, `hide()` lalu
`onPress`, dan portal yang dibuat ulang tiap tampil (notifikasi selalu paling atas — RC-S133.6.1).

## 2. `<Modal>` bergaya jendela dialog (`desktop/shims/modal-desktop.js`, `desktop/shims/react-native.js`, `metro.config.js`)

Di HP, pemilih (Pilih Akun/Anggota/Pinjaman/Rekening, Filter History, dsb. — 39 modal `animationType="slide"`)
tampil **layar penuh meluncur dari bawah**, dan lembar konfirmasi **menempel di bawah layar**. Di desktop:

- Modal **non-transparan** → **jendela dialog di tengah** (maks. 760 × 720 px), latar redup, klik di luar atau
  **Esc** = tutup (memanggil `onRequestClose` yang sama), animasi *fade*.
- Modal **transparan** → animasi *slide* diganti *fade*; lembar yang menempel di bawah (`justify-content:
  flex-end`) **dipusatkan** dan sudut bawahnya ikut dibulatkan.
- Isi, urutan tombol, dan handler setiap modal **tidak diubah** — tidak satu layar pun disunting.

Pemasangan: saat `KOPKU_DESKTOP=1` + platform `web`, `metro.config.js` mengalihkan `react-native` ke
`desktop/shims/react-native.js` (= react-native-web apa adanya, kecuali `Modal`). Untuk bundle Windows
siap-pakai yang sama dilakukan `scripts/tambal-renderer-rc-s133.6.6.js` (paket Windows): modul baru
dari `modal-desktop.js` + ekspor `default` Modal react-native-web dialihkan ke pembungkusnya.
