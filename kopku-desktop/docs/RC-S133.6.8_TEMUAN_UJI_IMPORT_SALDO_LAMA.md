# RC-S133.6.8 — Temuan uji import Saldo Lama ("Manaz", 13 Oktober 2026)

Berlaku untuk **KOPKU RC-S133.6.8** (source HP/RC) dan **KOPKU Desktop Windows 1.0.23**. Dasar: RC-S133.6.7 / Windows 1.0.22. **Skema database TETAP v82** (tanpa migrasi).

## Latar
Pengguna mengimpor berkas dummy *Import-Saldo-Lama-Koperasi-Dummy-Sejahtera.xlsx* (saldo per 30/06/2026) ke koperasi "Manaz".

- **Percobaan pertama.** Cut-off dibiarkan "hari ini" (13/10/2026) dan Kebijakan Produk Simpanan Berjangka belum aktif. Akibatnya:
  - Simpanan Berjangka Rp15.000.000 tidak tercatat.
  - Akumulasi penyusutan menjadi 4.550.000, seharusnya 3.800.000.
  - "Saldo Awal Belum Sesuai" bersaldo Rp14.250.000.
  - Meski begitu, laporan tetap berstatus **Seimbang** tanpa peringatan apa pun.
- **Percobaan kedua.** Cut-off 01/07/2026 dan kebijakan sudah aktif. Semua angka sama dengan hitungan independen (0 selisih), tetapi masih ada dua cacat tampilan:
  - CALK tidak menyebut Simpanan Berjangka.
  - Subjudul Arus Kas menampilkan teks "·" apa adanya.

Kondisi percobaan pertama direproduksi persis di uji, sampai Rp1.

## Pinjaman yang sudah lunas — cara mengisi
- **Jangan isi di sheet 3** (Pinjaman). Sheet itu hanya untuk pinjaman yang masih berjalan. Bila terisi pun aman: baris pinjaman lunas dilewati, tidak ada piutang, dan tidak muncul di daftar Pinjaman.
- **Jasa yang sudah dibayar** pinjaman itu pada tahun buku berjalan ditulis di **sheet 6** (per anggota, dijumlah dengan jasa pinjaman lain milik anggota yang sama). Angka ini dipakai pembagian SHU jasa usaha.
- **Pendapatan jasanya** sudah termasuk dalam saldo **4-1000 Pendapatan Jasa Pinjaman** di **sheet 7**.
- Riwayat angsuran pinjaman lunas tidak dibawa ke KOPKU. Saldo lama hanya membawa posisi per cut-off.
