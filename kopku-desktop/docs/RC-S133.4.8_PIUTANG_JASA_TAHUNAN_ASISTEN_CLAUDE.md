# RC-S133.4.8 — Piutang Berjalan, Satuan Jasa Pinjaman, Asisten Claude

KOPKU source RC-S133.4.8 · KOPKU Desktop 1.0.11 · skema tetap **v80** (tanpa migrasi).

## §A Masalah yang dilaporkan

Data awal diimpor dari `Template-Import-Data-Awal-Koperasi-final.xlsx`:
pokok pinjaman awal Rp308.988.390, sisa pokok ±Rp258,9 juta, 72 pinjaman aktif.
Dashboard menampilkan **Piutang Berjalan Rp824.551.194** dan Tunggakan Rp92.297.009.

Penyebab (direproduksi persis dengan bundle desktop asli + berkas pengguna):

1. **Jasa Persen dibaca per BULAN.** Di KOPKU (form pinjaman maupun import),
   "Jasa Persen" adalah persen **per periode angsuran**. Berkas pengguna berisi
   angka **per tahun** (18, 6, 12, 4,8449, …). Pinjaman 10 juta 10 bulan "18"
   menjadi jasa 1,8 juta *per bulan* (18 juta total). Sisa jasa terjadwal
   membengkak menjadi Rp565.667.432.
2. **Kartu "Piutang Berjalan" menjumlah sisa angsuran** (pokok + jasa yang
   BELUM jatuh tempo). Jasa yang belum jatuh tempo belum menjadi piutang
   koperasi.

Rp258.883.762 + Rp565.667.432 = **Rp824.551.194** — sama dengan tangkapan layar.

## §B Perbaikan import (sheet "3. Pinjaman")

- Kolom baru opsional **Satuan Jasa** (PERIODE/TAHUN), tepat setelah Jasa Persen.
  - Kosong / PERIODE / BULAN → perilaku lama (per periode angsuran).
  - TAHUN / PER TAHUN / TAHUNAN → dibagi 12 (dibulatkan 8 desimal; 18 → 1,5).
  - TAHUN untuk tenor HARI/MINGGU **ditolak** (berapa hari/minggu per tahun adalah
    keputusan koperasi, tidak ditebak).
  - Berkas lama tanpa kolom ini terbaca sama persis seperti sebelumnya.
- Pemeriksaan sebelum import (`periksaSebelumImport`), berlaku untuk Saldo lama
  dan Transaksi baru:
  - **PERINGATAN "Jasa N pinjaman lebih besar dari pokoknya — Jasa Persen per tahun?"**
    bila total jasa sepanjang tenor > pokok sementara Jasa Persen dibaca per periode;
  - **INFO "Ringkasan N pinjaman"**: pokok awal, sisa pokok (piutang), sisa jasa
    terjadwal, sisa angsuran — dihitung dengan kalkulator jadwal yang sama dengan
    pinjaman baru (`hitungJadwalAngsuran`).
- Template: catatan Jasa Persen diperjelas; slide panduan Sheet 3 menambah poin
  "Hindari". Perbaikan ikutan: jumlah kolom inti template Transaksi Baru dulu
  angka tetap `9` dan akan memotong kolom "Angsuran Sudah Dibayar" setelah kolom
  baru disisipkan — kini dihitung dari labelnya.

## §D Pengaturan › Asisten Claude (baru)

Menghubungkan KOPKU ke Claude (Anthropic) memakai **API key milik koperasi**.

- **Koneksi**: API key (disimpan terenkripsi di SecureStore — Android Keystore /
  DPAPI Windows / Keychain macOS; tidak masuk database, backup, sinkron, log),
  pilihan model (Sonnet 5.5 disarankan, Opus 5.5, Haiku 5.5, atau id lain),
  sakelar "Kirim ringkasan angka koperasi", tombol Hubungkan/Simpan & Uji,
  Uji Koneksi, Putuskan. Kunci baru **diuji dulu** sebelum disimpan — kunci salah
  tidak pernah menimpa kunci yang benar.
- **Tanya Claude**: tanya jawab, 4 saran pertanyaan, percakapan hanya di memori.
- **Baca saja.** Tanpa tool/function calling: Claude tidak dapat membuat jurnal,
  mengubah data, atau menjalankan menu.
- **Tanpa data pribadi.** Ringkasan yang dikirim hanya angka total (anggota aktif,
  simpanan per jenis, pokok pinjaman, sisa pokok, sisa jasa terjadwal, sisa
  angsuran, tunggakan) — tanpa nama/NIK/alamat/HP anggota. Dapat dimatikan.
- Izin: melihat = `pengaturan.view`; mengubah/menghapus kunci = `pengaturan.edit`.
- Desktop: `fetch` HTTPS lewat proses utama Electron (tanpa CORS/CSP).
  Butuh internet; fitur KOPKU lain tetap offline.
- Galat diterjemahkan: kunci ditolak (401), batas pemakaian (429), server sibuk
  (529), model tidak ada (404), saldo kredit habis, tidak ada internet.

   ulang memakai `Template-Import-Data-Awal-Koperasi-final-TERKOREKSI.xlsx`
   (Satuan Jasa = TAHUN pada 72 baris; angka Jasa Persen tidak diubah).
2. Periksa "Angsuran Sudah Dibayar": banyak pinjaman bertanggal 01/08/2026 berisi 0,
   sehingga angsuran 1 Sep & 1 Okt tercatat menunggak (Tunggakan Rp37,2 juta).
3. Asisten Claude: buat API key di console.anthropic.com › API Keys (butuh saldo
   kredit API), lalu Pengaturan › Asisten Claude › Hubungkan.
4. Windows: `npm install` lalu `npm run dist:win` (salin dulu
   `renderer/assets/node_modules/` dari renderer lama agar ikon tampil).
