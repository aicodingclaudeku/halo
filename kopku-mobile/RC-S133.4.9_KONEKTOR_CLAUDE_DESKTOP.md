## §B Cara kerja

```
Claude Desktop ──stdio (JSON-RPC/MCP)──▶ KOPKU Desktop.exe (ELECTRON_RUN_AS_NODE=1) electron/mcp/stdio.js
      └─ HTTP 127.0.0.1:<port acak> + token ─▶ proses utama KOPKU Desktop: electron/mcp/host.js
            └─ IPC ─▶ adapter renderer (electron/server/rendererAdapter.js, sama dengan server LAN)
                  └─ service KOPKU (sama dengan layar) ─▶ koperasi.db
```

- `stdio.js` tidak membuka database; bila KOPKU Desktop tertutup / konektor OFF, alat
  menjawab "Buka KOPKU Desktop … Konektor Claude Desktop: ON".
- Host hanya mendengar di 127.0.0.1, token acak 256-bit diperbarui setiap kali menyala
  (`<userData>/mcp/endpoint.json`), menolak header `Origin` (halaman web) dan `Host` selain
  localhost.
- Bertindak atas nama user KOPKU yang menyalakan: harus aktif, punya izin `view` resource
  alat (Permission Matrix), dan lisensi KOPKU valid — gagal tertutup.
- **Baca saja:** 11 alat, semuanya operasi baca adapter; tidak ada operasi bayar/setor/
  tarik/ajukan/cairkan/kas/anggota.buat/ubah (diuji: jumlah jurnal, simpanan, anggota,
  pinjaman tidak berubah setelah semua alat dipanggil).
- **Data pribadi selalu dibuang**: NIK, alamat, nomor HP/telepon, tempat & tanggal lahir,
  email, hash/salt/token, nomor rekening — apa pun pengaturannya.
- Setiap pemakaian dicatat ke `<userData>/mcp/audit.log` (nama alat, waktu, berhasil/tidak;
  tanpa isi data).
- Data yang dibaca alat dikirim ke Claude (Anthropic) sebagai bagian percakapan Anda.

## §G Langkah pengguna

1. `npm install` → `npm run dist:win` (salin `renderer/assets/node_modules/` dari renderer lama).
2. Pasang KOPKU Desktop 1.0.12, pasang Claude Desktop (claude.ai/download), buka sekali.
3. KOPKU › Pengaturan › Asisten Claude › 3: Nyalakan konektor → (opsional) Izinkan data per
   anggota → Pasang ke Claude Desktop.
4. Tutup Claude Desktop sepenuhnya (tray › Quit), buka lagi. KOPKU Desktop tetap terbuka.
5. Tanyakan di Claude Desktop, mis. "Berapa piutang berjalan koperasi saya?" → izinkan alat "kopku".
6. Bila konektor tidak muncul: Claude Desktop › Settings › Developer › lihat log server "kopku",
   atau gunakan "Pasang manual" di layar KOPKU.
