# RC-S133.1 — Hotfix: HP "Tidak dapat menghubungi desktop … Aborted"

## Gejala
Memindai QR di HP → "Tidak dapat menghubungi desktop (192.168.1.7:47821) … Aborted".
"Aborted" = permintaan HP tidak pernah dijawab (habis waktu), bukan ditolak.

## Akar masalah
Penyebab tersering adalah **Windows Firewall memblokir KOPKU Desktop**. Saat server sinkron pertama kali membuka port, Windows menampilkan dialog izin. Bila dialog ditutup atau dibatalkan, Windows membuat aturan **BLOKIR** masuk untuk program itu. Aturan blokir mengalahkan aturan izin. Installer sebelumnya (per pengguna, tanpa Administrator) tidak memasang aturan firewall. Penyebab lain dengan gejala sama: isolasi klien Wi-Fi, HP/komputer beda jaringan, atau Wi-Fi tanpa internet dengan data seluler HP menyala.

## Perbaikan
**Desktop (1.0.1)**
- `electron/hosts/firewallHost.js`: membaca status firewall tanpa hak Administrator (aturan izin KOPKU, aturan blokir untuk program, kategori jaringan). Tombol perbaikan menjalankan netsh lewat UAC: hapus aturan masuk lama program (termasuk blokir), lalu izinkan TCP 47821–47840 + program **hanya dari subnet lokal** (`remoteip=localsubnet`), semua profil.
- Layar Sinkron HP: kartu **Koneksi & firewall** berisi status, tombol **Izinkan di Firewall**, alamat uji `http://<IP>:47821/kopku/v1/ping` untuk browser HP, dan notifikasi "HP (IP) berhasil menjangkau desktop" saat alamat uji dibuka. Ada juga tawaran perbaikan otomatis sekali per sesi bila firewall perlu diperbaiki, dan tips (hotspot, data seluler, antivirus).
- Installer memasang aturan firewall saat instalasi (satu dialog UAC); uninstall melepasnya. Berlaku untuk dua jalur build: `npm run dist:win` (electron-builder, `installer/firewall.nsh`) dan `npm run dist:win-installer` (`installer/kopku-setup.nsi`, tanpa Windows). Versi 1.0.1. CRC installer diverifikasi (`scripts/verifikasi-installer.py`).

**HP (perlu APK baru agar pesan baru tampil)**
- `SyncKlien.ts`: uji jangkauan (`GET /kopku/v1/ping`) sebelum pemasangan dan saat sinkron gagal. Pesan membedakan **tidak menjawab** (firewall / isolasi Wi-Fi / data seluler) dari **menolak koneksi** (aplikasi desktop tertutup) dan memberi alamat uji. Tidak ada lagi "Aborted" polos.
- Termasuk hotfix kamera dari pengguna (`plugins/withKameraPindaiQr.js`: pesan jelas bila `expo-camera` belum terpasang).

APK yang sudah terpasang **tetap bisa dipakai**. Setelah firewall desktop diizinkan, pemindaian QR berhasil. APK baru hanya memperjelas pesan galat.
