# RC-S133.2 — Hotfix: "Desktop menolak permintaan (503)" saat Kirim data HP ke desktop

## Kejadian
HP berhasil dipasangkan, lalu memilih **Kirim data HP ke desktop**. Desktop menerima dan memasang data HP. Setelah itu:
- HP menampilkan "Desktop menolak permintaan (503)" dan tetap di "Pilih data awal";
- desktop pindah ke layar **Aktivasi Lisensi** tanpa akses ke Sinkron HP.

## Akar masalah
1. Layar setup desktop **memuat ulang halaman** setelah data masuk (`window.location.reload`). Memuat ulang mematikan pengendali server sinkron sesaat, sehingga HP yang sedang menunggu konfirmasi "selesai" mendapat 503. Sesi unggah yang tersimpan di memori ikut hilang.
2. Server sinkron desktop hanya dinyalakan di dalam gerbang lisensi/aplikasi. Di layar lisensi (setelah data masuk, setup dianggap selesai), server tidak menyala dan tidak ada tombol Sinkron HP.
3. Layar aktivasi desktop tidak menjelaskan bahwa lisensi desktop memakai kunci yang sama dengan HP, dan nama koperasi harus diketik ulang. Server menolak nama yang berbeda.

## Perbaikan
- Setup desktop tidak lagi memuat ulang halaman. Gerbang lisensi cukup dievaluasi ulang (`triggerLicenseRecheck`).
- `DesktopHost` menyalakan server sinkron **di luar** gerbang lisensi/login bila sudah terpasang. Di layar lisensi/login ada tombol **Sinkron HP · <status>** (kanan atas) yang membuka panel sinkron lengkap.
- HP **pulih sendiri**: bila konfirmasi hilang (desktop dimuat ulang, Wi-Fi putus), HP menanyakan baseline & kursor ke desktop (`INFO.kursorHp`). Bila desktop sudah memasang salinan HP, HP menyelesaikan langkah akhirnya tanpa mengirim ulang. Pemulihan juga dicoba saat layar Sinkron Desktop dibuka. 503 kini dijelaskan ("KOPKU Desktop sedang memuat… coba lagi").
- Layar aktivasi lisensi desktop menampilkan "Data “<nama>” sudah ada di komputer ini", menjelaskan aturan 1 HP + 1 PC, dan mengisi **Nama Koperasi** otomatis. Android tidak berubah (komponen `.web.tsx`).
- Desktop 1.0.2.
