# RC-S133.4.10 — KOPKU Desktop 1.0.13: Anti-bypass

Skema tetap **v80**. Renderer (UI & aturan bisnis) **tidak berubah** dari 1.0.12 — perubahan
hanya di proses utama Electron, konfigurasi build, dan konektor Claude Desktop.

## §A Temuan (audit 9 Okt 2026)

| # | Celah | Tingkat |
|---|---|---|
| 1 | `KOPKU_SMOKE=<berkas.js>` memuat skrip apa pun ke proses utama **aplikasi terpasang** (akses jendela & database) → lisensi/izin dapat dilewati | **Kritis** |
| 2 | `KOPKU_DEVTOOLS=1` membuka DevTools di aplikasi terpasang | Tinggi |
| 3 | Saklar `--remote-debugging-port`, `--inspect`, `NODE_OPTIONS` tidak ditolak → dapat dikendalikan dari luar | Tinggi |
| 4 | Kode aplikasi (app.asar) tidak divalidasi; dapat diubah lalu dijalankan | Tinggi |
| 5 | `ELECTRON_RUN_AS_NODE` aktif (dipakai konektor 1.0.12) | Sedang |
| 6 | `KOPKU_USERDATA` mengalihkan folder data aplikasi terpasang | Sedang |

Di luar cakupan RC ini (perlu keputusan/migrasi, lihat §E): database belum terenkripsi,
password mode Developer tertanam di renderer, installer belum ditandatangani.

## §B Perbaikan

**Proses utama (`electron/main.js`, `electron/keamanan.js` baru):**
- `KOPKU_SMOKE`, `KOPKU_DEVTOOLS`, `KOPKU_USERDATA` hanya berlaku saat dijalankan dari source
  (`electron .`, `app.isPackaged = false`). Aplikasi terpasang mengabaikannya.
- Aplikasi terpasang **menolak dibuka** dengan `--remote-debugging-port/-pipe/-address`,
  `--remote-allow-origins`, `--inspect*`, `--debug*`, `--js-flags`,
  `--auto-open-devtools-for-tabs` (pesan galat, keluar).
- Penjaga untuk **semua** webContents: DevTools langsung ditutup bila terbuka, `<webview>`
  ditolak, jendela baru ditolak (tautan https dibuka di browser), navigasi keluar dari `app://` ditolak.

**Lapisan biner (`package.json` › `build.electronFuses`, dipasang electron-builder):**

| Fuse | Nilai | Akibat |
|---|---|---|
| runAsNode | OFF | `ELECTRON_RUN_AS_NODE` tidak bisa memakai exe KOPKU sebagai Node |
| enableNodeOptionsEnvironmentVariable | OFF | `NODE_OPTIONS` diabaikan |
| enableNodeCliInspectArguments | OFF | `--inspect` diabaikan |
| enableEmbeddedAsarIntegrityValidation | ON | app.asar yang diubah → aplikasi menolak jalan |
| onlyLoadAppFromAsar | ON | kode tidak bisa diganti dengan folder `app/` |
| enableCookieEncryption | ON | cookie terenkripsi |

`scripts/verifikasi-fuse.js` berjalan otomatis setelah `npm run dist:win` (postdist:win) dan
**menggagalkan** build bila fuse di exe tidak sesuai.

**Konektor Claude Desktop tanpa RunAsNode:**
- Titik masuk baru `electron/entry.js`: `KOPKU Desktop.exe --kopku-mcp-stdio --data <folder>`
  menjalankan konektor (`electron/mcp/modeElectron.js`) tanpa jendela, tanpa database, tanpa
  mengambil kunci instance tunggal.
- Entri `kopku` gaya 1.0.12 (ELECTRON_RUN_AS_NODE) di `claude_desktop_config.json` yang menunjuk
  exe ini **diperbarui otomatis** saat KOPKU dibuka (server lain tidak disentuh).
- Cadangan bila cara utama tidak tersambung: `node <resources>/kopku-mcp/stdio.js` (salinan di luar
  app.asar lewat `extraResources`; tidak dimuat proses utama sehingga tidak membuka celah kode).
  Potongan JSON keduanya tampil di layar "Pasang manual".
- `asarUnpack` dihapus: tidak ada kode proses utama di luar app.asar.

`scripts/rakit-win-tanpa-npm.sh` kini mencetak peringatan: hasilnya tanpa app.asar & fuse —
untuk uji, bukan distribusi.

Source utama (`desktop/`): perbaikan proses utama yang sama (`keamanan.js`, penjaga variabel
uji, `electronFuses`, `verifikasi-fuse.js`), versi 1.0.13.

## §D Langkah pengguna

1. `npm install` → `npm run dist:win`. Pastikan baris terakhir: `verifikasi-fuse: OK`.
2. Pasang installer, buka KOPKU, coba transaksi biasa & cetak PDF.
3. Bila KOPKU **tidak mau terbuka** setelah build: ubah `enableEmbeddedAsarIntegrityValidation`
   menjadi `false` di package.json, build ulang, dan kabari hasilnya.
4. Konektor Claude: buka KOPKU sekali (entri lama diperbarui otomatis), lalu tutup & buka Claude
   Desktop. Bila tidak tersambung, pakai potongan "cadangan Node.js" di layar Pasang manual.

## §E Sisa risiko (belum dikerjakan)

- **Database tidak terenkripsi**: `koperasi.db` dapat diubah dengan program SQLite. Usulan:
  SQLCipher + rantai hash jurnal (deteksi perubahan) — butuh migrasi & keputusan.
- **Password mode Developer** tertanam di renderer (dapat dibaca dari bundle; mode ini
  mengubah tanggal "hari ini" aplikasi). Usulan: kode bertanda tangan server lisensi.
- **Tanda tangan installer** (code signing) belum ada: tanpa sertifikat, exe yang diubah tidak
  terdeteksi Windows. Siapkan sertifikat lalu isi `CSC_LINK`/`CSC_KEY_PASSWORD` saat build.
- Orang yang menguasai penuh laptop tetap dapat membongkar biner; tujuan RC ini membuat
  pembobolan jauh lebih sulit, bukan mustahil.
