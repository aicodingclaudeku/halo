# RC-S133.3 — Lisensi KOPKU Desktop otomatis dari HP

## Permintaan
"Bisa tidak lisensinya otomatis juga dari aplikasi mobile?"

## Batasan desain
Aplikasi HP tidak pernah menyimpan License Key; yang disimpan hanya token aktivasi bertanda tangan server. QR tetap **hanya** untuk pemasangan (tidak membawa lisensi).

## Mekanisme (aktivasi pendamping)
1. Setelah data awal/sinkron berhasil, HP bertanya ke desktop (`INFO.perluLisensi`).
2. Bila desktop belum berlisensi **dan** lisensi HP sendiri sah, HP mengirim token aktivasi + ID perangkatnya lewat kanal sinkron terenkripsi (`LISENSI_SPONSOR`). Kanal ini hanya terbuka untuk desktop yang dipasangkan lewat QR. Pengiriman otomatis paling sering sekali per 2 menit; ada juga tombol manual di HP.
3. Desktop memanggil `api/activate_companion.php` dengan token HP sebagai bukti. Server menegakkan 1 HP + 1 PC dan menerbitkan token **desktop sendiri**.
4. Desktop memverifikasi token Ed25519 secara lokal (sama dengan aktivasi biasa), menyimpannya, lalu gerbang lisensi terbuka. Token HP **tidak disimpan** di desktop.
5. Desktop perlu internet sekali untuk langkah 3. Aktivasi manual dengan License Key tetap tersedia.

## Berkas
- Server: `webkopku v3.2` — `api/activate_companion.php` (baru), `includes/AuditLog.php`.
- App: `LicenseService.activateLicenseCompanion()` (baru; `activateLicense()` tidak berubah), `SyncServer` (INFO `perluLisensi`, op `LISENSI_SPONSOR`, batas 2 menit), `SyncKlien.sponsoriLisensiDesktop()`, kartu "Lisensi desktop" di Sinkron Desktop (HP), status di layar aktivasi desktop.
- Uji arsitektur `LicenseRenewalRcS52` diperbarui: tepat dua jalur `activate*`. Jalur pendamping dipastikan tidak menerima `license_key` dan memakai `verifyActivationTokenOffline`.
